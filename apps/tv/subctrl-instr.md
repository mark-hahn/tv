# controlling subtitle choice and timing while emby is playing

- add a ui feature in the android app and web app to manage subtitles while watching a video
  - it should change subtitle track/srt
  - it should adjust timing
- pressing emby button in tv remote pane for 1 sec opens a pane named control pane
  - same pane size as other panes like info pane in web client
  - entire screen like remote in android
- ctrl pane has a top header row with 2 lines
  - the show name of video currently playing in emby is on left of header top row
    - if there are multiple emby players playing at once clicking on show name rotates through them
      - adjustments of subtitle choice and timing only affect selected player
  - there is a close X button in right side of header top row
  - the bottom row would have a left and right arrow buttons with OK in the middle
    - it would match second row in tv remote pane
      - same button borders, colors, and sizes
      - not same position in pane
        - located in second header row
    - there is a border around entire pane
      - like remote control pane
    - clicking on arrows would adjust subtitle offset timing in pane and in emby
      - each click would adjust timing by 100ms
    - OK will save settings and close pane
- the rest of the pane would be a scrollable list of cards
  - each card would have a subtitle choice
    - each card would show the subtitle name like the one in subtitle choice popup in emby
    - it would be `<name> (type)`
      - like `English (ASS)` or `opnABCD (SRT)`
      - we will have to experiment to get it to match emby exactly
  - clicking on card will change subtitles
- changes of subtitle track and/or timing will show live in emby
- ask me for help if instructions are ambiguous or incomplete or impossible
