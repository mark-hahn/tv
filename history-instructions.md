# add a history feature that tracks activity for a show

- add a db called history.sqlite in apps/srvr/data
  - add a record for every major event that happens for a show
  - duplicate events for a show should be deduped and update existing record
    - for now only event types considered as duplicates are chkDown, skipDown, rejDown, bkgndUpdate, browse, and preview
  - when a show is removed from tvdb.json remove events for show
  - the db record fields should be
    - tvdbId (authorative key)
    - showName (alternate key)
    - addTime (timestamp for record added to db)
    - updateTime (timestamp for last update of record)
    - updateCount (number of deduped events which is same as number of updates)
    - description (additional information about event)
    - type (one of these event types)
      - browse (selected in browse pane)
      - preview (shown in preview mode)
      - addEmby (added to emby)
      - remEmby (removed from emby)
      - torSent (torrent sent to qbittorrent)
        - description should be info in tor card
      - errTor (error sending torrent to qbittorrent)
        - description should be details about error
      - addQbt (new torrent in qbittorrent list)
        - description should be info in qbt card
      - remQbt (torrent disappears from qbittorrent list)
        - description should be info in qbt card
      - qbtFinished (torrent finished in qbittorrent list)
        - description should be info in qbt card
      - forceDown (forced down clicked in usb pane)
        - description is list of forced files
      - chkDown (show is in list of files found in usb at beginning of down check cycle)
        - description should be:
          - usb file path including file name
          - raw data from parseTorrentTitle
          - adjusted title from parseTorrentTitle
      - skipDown (show rejected silently)
        - description should be reason for skipping
      - rejDown (show rejected)
        - description should be reason for rejection
      - acceptDown (show accepted for downloading and is in waiting status)
        - description is info in down db record
      - startDown (download worker accepts file for rsync)
        - description is info in down db record
      - endDown (download worker finishes rsync)
      - errDown (error in down cycle)
        - same type of error as those shown in down pane list card
        - description is detailed msg for error
      - errorSync (error while downloading with rsync)
        - description is detailed msg for error
      - bkgndUpdate (show is processed in tvdb update)
        - description is tvdb field changes
    - suggest other event types
- add a button `History` to right side of right-arrow button
- button should toggle a history pane on and off
  - history pane should be inside map pane covering everything below header
  - when showing history pane make History button a light-gray background
  - history pane code should be in apps/client/src/components/history.vue
- the history pane should show a list of events in cards for selected show
  - if not in preview mode then selected show is from shows list
  - if in preview mode then selected show is from browse pane
  - if updateCount is greater than 0 then show event twice
    - once for addTime
    - once for updateTime (show msg `Updated`)
  - card should have all info from event db record
  - sort by time (addTime or updateTime)
- design a plan and document it in docs/history-plan.md
- suggestions are welcome
- ask me about contradictions or incomplete specs
- make no changes
