
# asr server
- create a server project at /root/apps/tv/apps/asr that is part of the monorepo /root/apps/tv
- name it @tv/asr
- @tv/asr will use the mistral AI Automatic Speech Recognition api to create subtitles for video files
- it should be a server that provides an endpoint `controlAsr(<asrArgs object>)` that returns an `<asrResult object>`.
- the endpoint should be proxied by nginx (/etc/nginx/conf.d/server.conf) to host POST https://hahnca.com/asr/controlAsr
- POST body is json `<asrArgs object>` with these fields
    - asrId: needed on status, dump, or kill commands
    - command: start, status, dump, or kill
        - start: start transcription of entire folder or one file
        - status: just return  `<asrResult object>`
        - dump: return entire log contents
        - kill: abort everything
    - folder:"path to video folder
    - file: optional video filename in folder
      - filename string
      - if null then process all video files in folder
    - sfx:srt file sfx
- every command returns the same json `<asrResult object>` with these fields:
    - asrId: id number hash generated by this server
    - filePath: path of current file being processed
    - status:  running, finished, killed, or error
    - numFilesFinished: number files processed
    - numFilesTotal: number total files to process
    - started: timestamp started
    - elapsedSecs: elapsed time in secs
    - progressFile: estimated percent progress of file currently being processed
    - progressAll: estimated percent progress of all files
    - estRemainingSecs: estimated secs until all files finished
    - log: entire contents of log file
      - used in dump command
    - error: error message
- examine project at /mnt/c/Users/mark/apps/mistral-asr

    - create new log for each asrId at "/root/dev/apps/tv/apps/asr/logs/`<timestamp yyyy/mm/dd_hh:mm:ss>-<asrId>.log" `
    - write same info to log as written by /mnt/c/Users/mark/apps/mistral-asr/asr.js

        - example video file:  "Less.Than.Perfect.s01e01.Pilot.DVDRip.AC3.XviD.avi" creates "Less.Than.Perfect.s01e01.Pilot.DVDRip.AC3.XviD.entst.srt"
