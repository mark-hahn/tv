# quit using emby

- interfacing with emby has been complicated and a source of a lot of problems
  - keeping a copy of emby data in tvdb has been a bad practice 
    - mirroring data in 2 places is always something to be avoided in all apps
  - playing video using emby from our code has been complicated and buggy

- we will stop using emby altogether
  - all data stored in emby will now be stored in tvdb records
    - much of emby data is already in tvdb
    - we won't simulate emby, we will just remove all emby code

## actions
- make a plan for the switch
- write the plan in kill-emby-plan.md
- make no changes other than writing to plan
