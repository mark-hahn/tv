### 1. Rotten Tomatoes Fuzzy Matching (Levenshtein)
This is the only instance of true fuzzy string matching (calculating edit distance). It compares a query string against candidate show titles to find the one with the smallest Levenshtein distance.

*   **File**: [apps/srvr/src/rotten.js](apps/srvr/src/rotten.js#L138)
*   **Logic**:
    *   Defines a local `levenshtein(a, b)` function.
    *   `chooseShow` function iterates through a list of shows, calculates the distance, and keeps the candidate with the minimum distance (`minDist`).

```javascript
// apps/srvr/src/rotten.js

function levenshtein(a, b) { ... }

function chooseShow(shows, query) {
  // ...
  let minDist  = Infinity;
  let minShows = [];
  for(const show of shows) {
    const dist = levenshtein(query, show.titleTrimmed);
    // ...
    if(dist < minDist) {
      minDist = dist;
      minShows = [show];
    }
  }
  // ...
}
```

### 4. TMDB Simple Match
A simpler instance that looks for a case-insensitive exact match in search results.

*   **File**: [apps/srvr/src/tmdb.js](apps/srvr/src/tmdb.js#L57)
*   **Logic**: Uses assertions of `toLowerCase()` equality against `original_name` or `name`.

```javascript
// apps/srvr/src/tmdb.js

// Find show with matching original_name
const matchingShow = res.results?.find(show => 
  show.original_name?.toLowerCase() === showName.toLowerCase() ||
  show.name?.toLowerCase() === showName.toLowerCase()
);
```
